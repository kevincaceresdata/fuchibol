# Recursos gratuitos para formarse como analista de fútbol

Curaduría propia (2026-11), verificada link por link. Ordenada para el perfil
"analista de datos que quiere entrar a un club del ascenso argentino".
Alternativa gratuita al curso "Asistente Táctico" (Maradona Menotti, $480.000 ARS).

## 1. Datos y analytics (tu fuerte — refuerza lo que ya hacés)

| Recurso | Qué es | Link |
|---|---|---|
| **Friends of Tracking** | Curso completo de tracking/event data hecho por data scientists de Man City, Liverpool, Barcelona y la FA. El curso de tracking data gratuito de referencia mundial. Inglés. | youtube.com/channel/UCUBFJYcag8j2rm_9HkrrA7w |
| **Soccermatics** | Curso escrito (readthedocs) de David Sumpter derivado del FoT: Python + modelos + visualización. Gratis, con código. | soccermatics.readthedocs.io |
| **StatsBomb Open Data** | Datos de evento + 360 de competiciones reales (Mundial 2022, Copa América 2024...). Los que ya usás en tu portfolio. | github.com/hudl/open-data |
| **SoccerNet** | Datasets y benchmarks de detección/tracking/re-ID de fútbol. Base de los experimentos del tracking-lab. | soccer-net.org |
| **Kaggle** | Cursos gratis de ML + datasets de fútbol (el "European Soccer Database" con 25k+ partidos). | kaggle.com |
| **awesome-soccer-analytics** (mascioto) | **Lista curada de recursos EN INGLÉS Y EN ESPAÑOL**, mantenida por un argentino. El índice definitivo del rubro. | github.com/matiasmascioto/awesome-soccer-analytics |
| **awesome-soccer-analytics** (wayton) | Índice similar, solo inglés, muy completo en datasets y papers. | github.com/kristopher-wayton/awesome-soccer-analytics |
| **Kloppy docs** | Librería open source para cargar tracking/event data de cualquier proveedor con un modelo unificado. | kloppy.openanalytics.dev |

## Qué NO se consigue gratis (y qué vende el curso de Manna)

1. Corrección en vivo de tu trabajo por un asistente de la Selección
2. Certificado de una escuela con licencia AFA/CONMEBOL
3. La cohorte (red de compañeros)

Regla para decidir: pagar un curso tiene sentido cuando ya trabajás en el
rubro y necesitás el sello. Para entrar al rubro, el certificado pesa menos
que un informe propio bien hecho + feedback de un senior (vía Mateo Muñoz).

## Ruta sugerida (tu "curso" de 4 semanas, $0)

1. **Semana 1-2 (tu proyecto):** taggear Agropecuario-Almagro (fecha 36) con
   Nacsport, generar el informe con este kit, llevarlo a la sede del club.
2. **En paralelo (vocabulario táctico):** playlist de Aldea Fútbol + artículos
   de MBP. Una hora por noche.
3. **Después del informe:** pasarle el análisis a Mateo para feedback (el
   "encuentro 7" del curso, pero gratis y con tu código).
4. **Permanente:** awesome-soccer-analytics (mascioto) como índice de
   consulta; FoT/Soccermatics cuando quieras subir el nivel de tracking.
